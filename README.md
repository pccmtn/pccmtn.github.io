# martinapocchiari.com

Personal academic website, served by GitHub Pages from this repository (`pccmtn.github.io`).

## Editing
- Each page is one file: `index.html` (Home), `research.html`, `talks.md`, `teaching.md`, `awards.md`, `media.md`, `job-market-advice.md`.
- Edit directly on github.com (pencil icon) and commit. The site rebuilds in about a minute.
- Menu items: `_config.yml` → `nav`.
- Look and feel: `assets/style.css`. Shared header/footer: `_layouts/default.html`.
- Profile photo: upload as `assets/photo.jpg`.
- `CNAME` holds the custom domain. Don't delete it.
